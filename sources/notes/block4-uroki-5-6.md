## Цели, результаты, артефакт

Студент строит сводную по текстовому ТЗ (строки/столбцы/значения/фильтр), проверяет «живость»
и сходимость итогов; выбирает тип графика под задачу; собирает лист «Отчёт» с выводами; обновляет
отчёт при добавлении данных; готовит «версию для руководителя» с локальной расшифровкой кодов
и обезличенный скриншот для галереи.

**Артефакт:** лист «Отчёт» = **3 сводные + 3 графика + 5 выводов**. Проверка: числовой квиз
«итоги сводных до и после добавления 20 строк». Портфель: файл с листом «Отчёт» + обезличенный
скриншот; пост в «Галерее отчётов».

## Поминутная структура (60 мин)

- **0–5 Вход** — скриншот эталонного дашборда: «это соберём за 40 минут, только текстом».
  ТЗ руководителя = задание на самостоятельный отрезок.
- **5–15 Видео-демо: первая сводная** — З4.1 (Регион × Месяц, выручка) + 3 мин «анатомии»
  сводной (строки/столбцы/значения/итог — единственная теория блока, после результата).
  З4.2: 3 вывода для руководителя; учим проверять интерпретацию по цифрам.
  H5P-пауза: «какой вывод не подтверждается числами?».
- **15–30 Практика по образцу** — З4.3 (вторая сводная), З4.4 (линейный график), З4.5 (топ-5
  барами), памятка выбора графика; З4.6 оформление.
- **30–50 Самостоятельно по ТЗ** — лист «Отчёт»: 3 сводные (регион×месяц; менеджер×категория;
  доля категорий в выручке) + 3 графика + «5 выводов» (агент формулирует, студент проверяет
  каждый по цифрам и правит; «красивые, но ложные» выводы — запланированная ловушка).
  Вызов: З4.7 срез/фильтр по региону.
- **50–57 Практикум обновления + версия для руководителя** — вставить 20 сделок из insert-файла →
  З4.8 → контроль: итог сводной = сумма столбца «Выручка». З4.9: сводная должна быть настоящей,
  не картинкой. Затем локальная расшифровка кодов менеджеров в копии «для руководителя»;
  скриншот в галерею — только с кодами.
- **57–60 Самопроверка и сдача** — чек-лист → числовой квиз → портфель → галерея → бейдж.

## Приёмы и правила

- **ТЗ на сводную** = строки / столбцы (порядок!) / значения (сумма или среднее) / итоги
  + проверка-контрольная сумма. Месяцы всегда «в календарном порядке» — указывать явно
  (буква Ф в КЗФП: Контекст → Задача → Формат → Проверка).
- **Правило двух проверок:** (а) контрольная сумма/сходимость итогов + (б) ручная проверка
  3 строк калькулятором или пересчёт другим способом.
- **3 сводные + 3 графика + 5 выводов** на листе «Отчёт»; выводы формулирует агент, студент
  проверяет каждый по цифрам (ловушка — правдоподобные ложные выводы).
- **Памятка «какой график для какой задачи»:** динамика → линия; сравнение → бары;
  структура → круговая (осторожно, ≤ 5 сегментов).
- **Обновление данных:** вставка 20 строк → «обнови сводные и графики» → расхождение итога
  с суммой столбца = 0; проверка «живости» кликом (не значения/картинка).
- **Безопасность:** версия для руководителя расшифровывается локально (ключ не покидает
  компьютер); наружу и в галерею — только обезличенные версии с кодами М1–М6.

## Приёмка и квиз

Чек-лист блока: ☐ 3 сводные «живые» ☐ итоги сходятся с суммами исходных столбцов (расхождение 0)
☐ 3 графика соответствуют задачам и подписаны ☐ 5 выводов проверены по цифрам ☐ отчёт пережил
добавление 20 строк ☐ версия для руководителя расшифрована локально, в галерее обезличенный
скриншот.

Автооценка: числовой квиз (общий итог выручки; итог по региону-лидеру; прибыль топ-менеджера;
новый итог после +20 строк) + 4 вопроса «выбери график под задачу». Бейдж: квиз ≥ 70% + портфель.
Полных текстов вопросов в docx нет — генерируются из паспорта датасета.

Рубрика курса (5 × 0–3, зачёт ≥ 11/15): в критерии «Качество артефакта» уровень 0 = «сводные
мёртвые», числа зашиты; уровень 3 = презентабельно, сводные живые, графики уместны.

## Карта типичных ошибок

- Месяцы в алфавитном порядке → календарный порядок указывать явно (буква Ф).
- Сводная «мёртвая» (значения/картинка) → З4.9, перестройка.
- Выводы агента не подтверждаются цифрами → студент правит каждый вывод; интерпретацию тоже проверяем.
- Круговая диаграмма на 20 категорий → памятка выбора графика.
- Итог сводной ≠ сумма столбца → потерянные строки/фильтры → рекламация
  («В столбце X строки N–M неверно: ожидалось …, получилось … . Исправь и покажи, что изменил»).
- Скриншот с расшифрованными ФИО ушёл в галерею → наружу только обезличенная версия.

Лестница подсказок: карточка-подсказка → частичный эталон → полный эталон после первой попытки
квиза + «Карта типичных ошибок» + форум.
