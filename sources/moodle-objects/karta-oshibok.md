# Карта типичных ошибок

Симптом → причина → что делать. Одна и та же ошибка повторяется у разных людей; карта нужна, чтобы не искать причину с нуля.

| Симптом | Причина | Что делать |
|---|---|---|
| Агент отвечает текстом, файл не меняется | Включён режим чата, а не агента | Переключить режим по чек-листу настройки и повторить запрос целиком. |
| Агент «не видит» файл | Нет доступа к папке или файл лежит вне рабочей папки | Дать доступ, в запросе называть имя файла и лист. |
| Копия не появилась | Агенту дано право только читать | Дать право записи, проверять список файлов, а не текст ответа. |
| Изменился исходник | В запросе не было правила копий | Вернуть исходник из резервной копии, работать с `_v1`, дальше `_v2`. |
| Сумма не сошлась | Скидка введена долей (0,05) вместо процентов (5) или взята не та колонка | Рекламация: «в столбце X ожидалось …, получилось …». |
| Три строки сошлись, а сумма нет | Проверена только часть данных | Сверять и сумму, и выборку строк; искать пустые значения в количестве и цене. |
| Вместо файла пришла картинка | Платформа ответила как чат | Нужен режим исполнения с сохранением файла; картинка результатом не считается. |
| Агент сам «обезличил» данные | Очистка отдана агенту — данные уже ушли из контура | Очистка только локально, до загрузки. Загружать уже очищенный файл. |
| В файле, ушедшем агенту, остались имена | Нарушен нулевой шаг: пропущена колонка или примечания | Вернуться к паспорту данных, проверить скрытые листы и примечания, удалить файл из диалога. |
| Ключ попал агенту или в портфель | Лист-ключ лежал в общей папке | Ключ хранится отдельно и локально; сдавать работу заново с новым ключом. |
| Поиск по артикулу «нашёл не то» | В одном листе артикул текстом, в другом числом | Просить список ненайденных строк, а не молчаливое исправление; проверять тип ключа. |
| Даты не считаются месяцем | Дата записана текстом | Просить список проблемных строк и отдельный столбец «Месяц», без молчаливой правки. |
| Агент удалил строки «для чистоты» | В запросе не было запрета на удаление | Удаление — только явным запросом; восстанавливать версию, добавлять в журнал. |
| Итог сводной не равен сумме столбца | Потерялись строки или остался включённый фильтр | Рекламация с двумя числами; проверить фильтры и пустые строки. |
| Сводная «мёртвая»: вставленные значения или картинка | Агент сымитировал сводную | Просить настоящую сводную и проверять обновлением: добавить строку — итог должен измениться. |
