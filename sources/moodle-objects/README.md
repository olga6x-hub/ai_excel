# Три объекта Moodle для курса «Табличный редактор текстом»

Материалы подготовлены файлами; в Moodle объекты создаются один раз при сборке курса.
Все тексты нейтральны: без названий продуктов, без персональных данных, только учебные файлы.

| Файл | Что это | Куда в Moodle |
|---|---|---|
| `biblioteka-zaprosov.csv` + `.html` | 12 запросов (2 на блок), дословно из карточек | Элемент **База данных (Database)**, 5 полей — см. ниже |
| `glossarij.csv` | 30 терминов курса | **Глоссарий** → «Импорт записей» (CSV) |
| `karta-oshibok.html` + `.md` | 15 типичных ошибок: симптом → причина → что делать | **Страница (Page)** в нулевом разделе |

## 1. Библиотека запросов (Database)

Поля:

| Поле | Тип | Настройки |
|---|---|---|
| Категория | Выбор (menu) | Блок 1 … Блок 6 |
| Название | Текст (text) | обязательное |
| Запрос | Текстовая область (textarea) | обязательное, 60 строк |
| Что проверять | Текст (text) | — |
| Что не класть | Текст (text) | — |

Настройки активности: «Требуется одобрение» — выключено (на пилоте), «Разрешить комментарии» —
включено. Права: студент добавляет записи, видит только свои (на пилоте); на потоке — видит все,
после модерации.

Записи переносим вручную из `biblioteka-zaprosov.html`: у Moodle нет штатного CSV-импорта в Database,
а полурабочий preset хуже ручного переноса 12 записей (10 минут работы).

## 2. Глоссарий (Glossary)

1. Создать «Глоссарий», тип — «Вторичный» (или основной, если других нет).
2. Включить **автосвязывание** записей по содержанию курса.
3. «Импорт записей» → CSV → файл `glossarij.csv`, разделитель «запятая», кодировка UTF-8.
4. После импорта включить «Показывать алфавит» и «Показывать ссылку “Все”».

Формат файла: две колонки — «концепция», «определение». Первая строка — заголовок, при импорте
её пропустить (в Moodle есть галочка).

## 3. Карта ошибок (Page)

1. Элемент «Страница», название «Карта типичных ошибок».
2. Режим — HTML, вставить содержимое `karta-oshibok.html` (внутри только разметка и стили таблицы).
3. Поставить в нулевом разделе и продублировать ссылку в карточках уроков, где ошибки специфичны.
