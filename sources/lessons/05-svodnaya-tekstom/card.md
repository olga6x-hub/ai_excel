# Урок 5. Сводная текстом

**Время:** озвучка ~3 мин · практика ≈ 30 мин · квиз 15 мин — итого ≈ 48 мин.

Карточка практики. Работаете на `sales_2025_safe_v3.xlsx` (результат уроков 2–4), лист «Сделки»:
1800 строк за 12 месяцев 2025. Результат урока — три сводные и три вывода для руководителя,
проверенные по цифрам.

## Анатомия сводной (единственная теория урока)

Текстовое ТЗ на сводную состоит из пяти частей:

| Часть | Что указываем | Пример |
|---|---|---|
| Строки | по чему группируем вниз | Регион |
| Столбцы | по чему группируем вправо + **порядок** | Месяц, в календарном порядке |
| Значения | что считаем и как | сумма Выручки |
| Итоги | нужны ли общие | с общими итогами |
| Проверка | с чем сверяем | итог = сумма столбца «Выручка», расхождение 0 |

Календарный порядок указываем явно: иначе месяцы выстроятся по алфавиту и апрель окажется
раньше января. Формат — такая же часть запроса, как и задача (буква «Ф» в КЗФП).

## Запросы урока

| № | Текст запроса |
|---|---|
| З4.1 | Построй сводную таблицу на новом листе «Сводная»: строки — Регион, столбцы — Месяц (в календарном порядке), значения — сумма Выручки, с общими итогами. Данные — лист «Сделки» файла …_v3.xlsx. Покажи итог по всем регионам и сверь его с суммой столбца «Выручка». |
| З4.2 | Сформулируй 3 вывода из этой сводной для руководителя: что растёт, что падает, где аномалия. Каждый вывод подкрепи конкретными числами из таблицы. |
| З4.3 | Вторая сводная на листе «Сводная 2»: строки — Менеджер (коды), столбцы — Категория, значения — сумма Прибыли. Добавь итог и отсортируй по убыванию итога. |

Третья сводная (самостоятельно): доля каждой категории в общей выручке.

## Три сводные + три графика + три вывода

К концу урока 6 на листе «Отчёт» у вас будет полный комплект. В этом уроке собираем сводные
и формулируем выводы: агент предлагает черновики, вы отбираете и записываете три итоговых вывода,
каждый проверяете по цифрам таблицы.
Правдоподобный, но не подтверждённый числами вывод — запланированная ловушка этого урока.

## Что сдаёте в портфель

- Файл версии v4 с листами «Сводная», «Сводная 2» и третьей сводной по категориям.
- Пять выводов для руководителя, каждый с числом из таблицы и вашей пометкой «проверено».
- Запись в журнале проверок: итог сводной против суммы столбца, расхождение 0.
- Два своих запроса в «Библиотеку запросов».

Безопасность: в файле, который видит агент, только коды менеджеров. Расшифровка — локально,
в копии «для руководителя».

## Взнос в библиотеку запросов

Два лучших запроса урока — в общую библиотеку курса (Database «Библиотека запросов»):

1. З4.1 (Построй сводную таблицу на новом листе «Сводная»: строки — Регион, столбцы — Месяц (в календарном порядке), значения — сумма Выручки, с общими итогами. Данные — лист «Сделки» файла …_v3.xlsx. Покажи итог по всем регионам и сверь его с суммой столбца «Выручка».).
2. З4.3 (Вторая сводная на листе «Сводная 2»: строки — Менеджер (коды), столбцы — Категория, значения — сумма Прибыли. Добавь итог и отсортируй по убыванию итога.).

Не кладите: запросы с именами клиентов, ключи справочников, пути к вашим рабочим файлам.

## Квиз

Числовые вопросы: общий итог выручки, итог по региону-лидеру, прибыль топ-менеджера,
доли категорий (допуск ±0,5%). Плюс ситуационный вопрос «какой вывод не подтверждается
числами». Порог 70% + портфель = бейдж блока 4.
Квиз общий для уроков 5–6, сдаётся после урока 6.

## Лестница подсказок

1. Подсказка: начните с пяти частей ТЗ на сводную, не забудьте календарный порядок.
2. Частичный эталон: готовые формулировки З4.1 и З4.3, числа своего варианта.
3. Полный эталон `reference_b4.xlsx` — после первой попытки квиза.

## Карта типичных ошибок

- Месяцы в алфавитном порядке → указывать календарный порядок в запросе.
- Итог сводной не равен сумме столбца → потерялись строки или остался фильтр → рекламация.
- Сводная «мёртвая»: вместо неё вставленные значения или картинка → перестроить (проверяется
  в уроке 6).
- Выводы агента звучат складно, но цифрами не подтверждаются → правьте каждый вывод руками.
- В сводной оказались имена менеджеров вместо кодов → нарушение нулевого шага, вернитесь
  к уроку 2.
