# Урок 3. Столбцы словами

**Время:** озвучка ~3 мин · практика ≈ 30 мин · квиз 16 мин — итого ≈ 49 мин.

Карточка практики. Работаете на очищенном файле `sales_2025_safe.xlsx` (результат урока 2),
лист «Сделки». Агент подключается только после нулевого шага — он уже сделан.

Цель урока: восемь расчётных столбцов текстом, ноль выученных функций.
Список столбцов: **Выручка, Прибыль, Крупная сделка, Поставщик, Месяц, Квартал, Маржа %, Бонус**.
Четыре последних и «Поставщик» разбираются в уроке 4 — здесь делаем первые три и бонус с сегментом.

## Шаблон запроса «расчётный столбец»

```
В файле <имя> на листе <лист> добавь столбец <название> = <логика словами>.
Покажи сумму столбца и 3 примера строк. Объясни словами, как считал.
Сохрани как <имя>_v<N>.xlsx. Исходный файл не меняй.
```

Четыре части запроса (КЗФП): **К** — файл, лист, колонки; **З** — бизнес-логика словами без
названий функций; **Ф** — формат результата и версия файла; **П** — сумма столбца, три примера,
объяснение словами.

Условный признак формулируется так: «“Да”, если [условие], иначе “Нет”. Покажи количество
каждого значения».

## Две привычки урока

1. **Правило копий.** Агент работает с копией, версии `_v1`, `_v2`; исходная выгрузка неприкосновенна.
2. **Две проверки.** Контрольная сумма столбца + пересчёт трёх строк калькулятором (или пересчёт
   другим способом через З3.10). Проверка — часть запроса, а не отдельная просьба потом.

Удалять строки агент может только по вашей явной просьбе и с записью в журнал.

## Карта типичных ошибок

- Скидка и проценты перепутаны местами → проверьте порядок чисел вручную → рекламация.
- Проверку попросили отдельным сообщением и получили «всё верно» без чисел → проверка входит
  в первый же запрос.
- Агент «помог» и удалил строки → удаления только явным запросом, восстановите версию.
- В файле, ушедшем агенту, оказались имена менеджеров → нарушение нулевого шага, вернитесь
  к уроку 2.
- Числа зашиты в формулы вместо логики словами → попросите объяснить словами, как считал.
