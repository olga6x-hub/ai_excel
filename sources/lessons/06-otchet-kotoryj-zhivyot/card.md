# Урок 6. Отчёт, который живёт

**Время:** озвучка ~3 мин · практика ≈ 30 мин · квиз 15 мин — итого ≈ 48 мин.

Карточка практики. Работаете на файле версии v4 (листы «Сделки», «Сводная», «Сводная 2»).
Результат урока — лист «Отчёт»: **3 сводные + 3 графика + 5 выводов**, который пережил
добавление двадцати новых строк.

Для практикума обновления понадобится файл `insert_20rows_safe.xlsx` из папки вашего варианта:
это 20 уже очищенных сделок декабря 2025.

## Памятка: какой график для какой задачи

| Задача | Тип графика | Ограничение |
|---|---|---|
| Динамика во времени | линия | точки в календарном порядке |
| Сравнение объектов | столбцы (горизонтальные для длинных названий) | сортировка от большего к меньшему |
| Структура, доли | круговая | не больше 5 сегментов, иначе глаз не различает доли |

## Запросы урока

| № | Текст запроса |
|---|---|
| З4.4 | Построй линейный график выручки по месяцам на листе «Отчёт». Заголовок, подписи осей, формат чисел — рубли с разделителем тысяч. Месяцы — в календарном порядке. |
| З4.5 | Построй горизонтальную столбчатую диаграмму топ-5 товаров по выручке, отсортируй от большего к меньшему, подпиши значения. |
| З4.6 | Приведи лист «Отчёт» к презентационному виду: единый формат чисел, ширины столбцов, заголовки блоков, ничего не наезжает друг на друга. Покажи превью результата. |
| З4.7 | Добавь фильтр (срез) по Региону, чтобы все сводные и графики на листе «Отчёт» перестраивались при выборе региона. |
| З4.8 | В лист «Сделки» добавлены 20 новых строк. Обнови все сводные и графики так, чтобы новые данные вошли. Покажи новый общий итог и расхождение с суммой столбца «Выручка» — должно быть 0. |
| З4.9 | Подтверди, что сводные — настоящие сводные таблицы редактора, а не вставленные значения или картинки. Покажи, как проверить это кликом. |

## Практикум «добавились 20 строк»

1. Скопируйте содержимое `insert_20rows_safe.xlsx` в конец листа «Сделки» (строки 1801–1820).
2. Отправьте З4.8.
3. Контроль: новый общий итог сводной равен сумме столбца «Выручка», расхождение **0**.
4. Если расхождение не ноль — потерялись строки или остался срез: рекламация по шаблону
   («в сводной итог …, в столбце …, расхождение …, найди причину и покажи исправление»).

## Версия для руководителя

Расшифровку кодов менеджеров (М1–М6) делаете **локально**, в отдельной копии файла, с помощью
своего листа-ключа. Ключ агенту не уходит. В общую галерею курса кладёте только обезличенный
снимок экрана — с кодами, без имён и без телефонов.

## Что сдаёте в портфель

- Файл с листом «Отчёт»: 3 сводные, 3 графика, 5 выводов с числами.
- Запись в журнале проверок: итог сводной до и после добавления 20 строк, расхождение 0.
- Обезличенный снимок экрана листа «Отчёт» + пост в «Галерее отчётов».
- Два своих запроса в «Библиотеку запросов».

## Взнос в библиотеку запросов

Два лучших запроса урока — в общую библиотеку курса (Database «Библиотека запросов»):

1. З4.4 (Построй линейный график выручки по месяцам на листе «Отчёт». Заголовок, подписи осей, формат чисел — рубли с разделителем тысяч. Месяцы — в календарном порядке.).
2. З4.8 (В лист «Сделки» добавлены 20 новых строк. Обнови все сводные и графики так, чтобы новые данные вошли. Покажи новый общий итог и расхождение с суммой столбца «Выручка» — должно быть 0.).

Не кладите: запросы с именами клиентов, ключи справочников, пути к вашим рабочим файлам.

## Квиз

Числовые вопросы: общий итог выручки, итог по региону-лидеру, прибыль топ-менеджера,
новый итог после добавления 20 строк (допуск ±0,5%). Плюс четыре вопроса «выбери график
под задачу». Порог 70% + портфель = бейдж блока 4.
Квиз общий для уроков 5–6 — сдаётся после этого урока.

## Лестница подсказок

1. Подсказка: начните с памятки «какой график для какой задачи» и не забудьте подписи осей.
2. Частичный эталон: готовые формулировки З4.4 и З4.8, числа своего варианта.
3. Полный эталон `reference_b4.xlsx` — после первой попытки квиза.

## Карта типичных ошибок

- Сводная «мёртвая»: вместо неё вставленные значения или картинка → З4.9, перестроить.
- После добавления строк итог не изменился → сводные не обновились → рекламация.
- Итог сводной ≠ сумма столбца → потерянные строки или активный срез.
- Круговая диаграмма на двадцать сегментов → заменить на столбцы.
- Месяцы в алфавитном порядке → указывать календарный порядок в запросе.
- Снимок экрана с расшифрованными именами ушёл в галерею → наружу только обезличенная версия.
